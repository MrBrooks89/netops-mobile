# NetOps Mobile

A cross-platform networking toolkit for beginners, IT support, network
engineers, and security professionals. Android-first (built and tested on
Fedora Linux), architected for iOS later without a rewrite.

**Status:** M0 (bootstrap) — implementation plan in [docs/IMPLEMENTATION_PLAN.md](docs/IMPLEMENTATION_PLAN.md)

## Stack

- React Native 0.86 + Expo SDK 57, TypeScript strict
- expo-router (file routes, typed links)
- Pure-TypeScript `src/core` (IP math, registry, error taxonomy) — zero RN imports
- CNG + dev-client workflow ([ADR-001](docs/adr/001-cng-dev-client-from-day-one.md))

## Getting started

```bash
# 1. Toolchain (JDK 21, Android SDK, AVD) — see docs/ENVIRONMENT.md
scripts/setup-env.sh

# 2. Deps
pnpm install

# 3. Headless emulator (KVM-accelerated, runs in Docker)
scripts/emu.sh up && scripts/emu.sh wait

# 4. Metro + app
pnpm start            # then press 'a' to open on the emulator

# Quality gates (same as CI)
pnpm typecheck && pnpm lint && pnpm format:check && pnpm test
```

## Layout

```
app/            expo-router routes (tabs, generic /tool/[id] route)
src/core/       pure TS: ip math, Result/ToolError, tool registry — no RN imports
src/features/   one directory per tool (M1+: subnet-calculator, …)
src/platform/   capability interfaces + platform impls (M3+)
src/data/       repositories, SQLite, export (M2+)
src/ui/         theme tokens + UI primitives
android/        GENERATED by expo prebuild — gitignored
```

## Tool registry

Tools register in `src/core/registry/registry.ts`; the dashboard renders from
the registry and `/tool/[id]` routes to the tool's component. Adding a tool
never touches routing or the dashboard.
